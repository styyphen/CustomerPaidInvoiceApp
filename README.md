# Customer Paid Invoice App

A performance benchmarking application for postal code grouping operations.

## Overview

This project is a C# application that benchmarks postal code grouping functionality using **BenchmarkDotNet**. It measures and analyzes the performance characteristics of postal grouping algorithms.

## Features

- **Performance Benchmarking**: Comprehensive benchmarking of postal grouping operations
- **.NET 10.0 Runtime**: Built on .NET Core 10.0
- **Detailed Metrics**: Generates detailed performance reports and analysis
